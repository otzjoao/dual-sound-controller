Dois aparelhos de áudio. Um app só.

O Dual Sound Controller é um app mobile feito em Flutter para encontrar, conectar e controlar dispositivos de áudio por Bluetooth, tudo de uma tela só.

Rodar o projeto Ver no GitHub

Onde o projeto está

A base está pronta. O app abre numa tela inicial com o nome, a seção de dispositivos, o card com o estado de conexão e o botão de busca. A interface já está separada em telas e widgets, e existe um teste de widget que confere a renderização.

A parte Bluetooth ainda não existe. Hoje o botão não procura nada de verdade. A próxima etapa é adicionar a biblioteca BLE e criar o serviço que descobre e conecta dispositivos.

O que o app quer fazer

A ideia é centralizar o gerenciamento de dispositivos de áudio numa interface única e simples.

  • Buscar dispositivos próximos
  • Identificar o que foi encontrado
  • Conectar e desconectar
  • Reunir os conectados numa tela só
  • Ler e escrever características BLE
  • Investigar controle de volume
  • Estudar sincronização de áudio
  • Rodar com testes automatizados

Por que BLE não é áudio

Bluetooth de baixa energia (BLE) serve para conversar com um dispositivo por serviços e características. Ele não é o caminho que as caixas de som usam para tocar música, que costuma ser Bluetooth Classic com A2DP.

Por isso o projeto trata as duas coisas separado: primeiro descoberta, conexão e controle por BLE, depois uma pesquisa à parte sobre saída e sincronização de áudio, que muda de Android para iOS. Essa investigação faz parte do desenvolvimento.

Roadmap

  1. Fase 1 · Estrutura inicial concluída

    Projeto Flutter, ambiente Android, interface inicial, teste de widget, Git e GitHub.

  2. Fase 2 · Bluetooth/BLE próxima

    Biblioteca BLE, modelo de dispositivo, serviço Bluetooth, descoberta, conexão e desconexão.

  3. Fase 3 · Controle dos dispositivos planejada

    Leitura e escrita de características, controle individual e investigação de volume.

  4. Fase 4 · Áudio planejada

    Limites do áudio Bluetooth, A2DP e sincronização entre dispositivos no Android e no iOS.

  5. Fase 5 · Refinamento planejada

    Animações, tratamento de erros, mais testes, documentação e uma versão para demonstrar.

Rodar na sua máquina

Você precisa do Flutter SDK, do Android SDK, do Git e de um celular Android ou emulador. Confira a instalação com flutter doctor e depois:

git clone https://github.com/otzjoao/dual-sound-controller.git
cd dual-sound-controller
flutter pub get
flutter devices
flutter run

Para rodar os testes, use flutter test.
